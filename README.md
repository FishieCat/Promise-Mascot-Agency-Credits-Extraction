# Promise-Mascot-Agency-Credits-Extraction
Extracts Promise Mascot Agency credits (Unreal Engine 4.27)

1. extract `CreditsContents.json` from the game using [FModel](https://github.com/4sval/FModel)
2. run `python json2moby_ue427_promisemascotagency.py CreditsContents.json`
3. clean up `CreditsContents.json_moby_2.txt`
4. ignore the ugly ugly code in the py file of this repository
